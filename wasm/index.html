ブラウザの動作確認結果

このサイトで公開しているLUTIAについて、次の結果を確認しています。

Android / Chrome
問題なく動作しました。
iPhone / Safari
問題なく動作しました。
Android / 標準ブラウザ
エラーが発生しました。エラーになる場合はChromeで開いてください。

今回確認した環境での結果です。端末の機種、OS・ブラウザのバージョン、Androidの標準ブラウザの具体的な製品名は未記録です。すべての端末・ブラウザでの動作を保証するものではありません。

自分のスタックもWebに公開する

HyperZebraでスタックを開き、ファイルメニューの「Web用に書き出す…」を選びます。出力したフォルダをWebサーバーに配置すると、その中の index.html から実行できます。

手元で確かめるときは、書き出し後の「ブラウザで試す」を使ってください。ファイルを直接開く file:// では動作しません。
